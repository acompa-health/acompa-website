# Acompa Website

Static public website for Acompa Health.

## GitHub Pages

Until a custom domain is connected, the project Pages URL is expected to be:

```
https://acompa-health.github.io/acompa-website/
```

In GitHub repository settings, enable Pages with:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/`

The site is intentionally dependency-free: `index.html`, `favicon.ico`, and files under `assets/` are enough to serve it.

## Assets

- `assets/cats_cradle_hero.jpg` is the selected hero image.
- `assets/acompa-icon-transparent.png` and `favicon.ico` come from Acompa brand assets.
